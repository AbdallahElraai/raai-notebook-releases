# Raai Notebook — Releases

**Your notebook. On your PC. Private by default.**

Raai Notebook is a pen-first digital notebook for Windows that replaces a paper notebook.
It works with Wacom, XP-Pen, Huion and any Windows Ink pen.

This repository only hosts the official installers and update feed. The app checks it for
new versions and updates itself automatically.

## Download

Get the latest **`Raai Notebook Setup x.y.z.exe`** from
[Releases](https://github.com/AbdallahElraai/raai-notebook-releases/releases/latest), run it,
and start writing. Updates after that are automatic.

> Windows SmartScreen may show "Windows protected your PC" because the installer isn't
> code-signed yet. Click **More info → Run anyway**.

## Privacy

No account, no analytics, no telemetry. Your notebook stays on your PC. The only network
request the app makes is the update check against this repository, and you can turn it off
in Settings → General.
